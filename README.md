# FN WORKWEAR & SAFETY

Premium editorial B2B website for FN Workwear & Safety, Sialkot, Pakistan.

## Website
- Responsive static website with desktop and mobile navigation.
- Product-family detail views for industrial workwear, high-visibility clothing, protective apparel and corporate uniforms.
- Interactive pointer-controlled conceptual garment illustration.
- Quote form prepares an email to the business; it does not store or transmit submissions to a server.
- SEO metadata, Open Graph tags, favicon, robots.txt and sitemap.

## Publish
The GitHub Actions workflow builds a static artifact on pushes. Deployment is gated by the repository variable `PUBLISH_SITE=true`; the site remains unpublished until the owner approves and enables that variable.

## Accuracy notes
- Photography is illustrative editorial imagery and is not evidence of FN's actual factory, products or facilities.
- The interactive garment is a conceptual visual study, not a physical production sample.
- No certifications, audited facilities, compliance claims, manufacturing capacity, MOQ, lead times or export track record are asserted.
- Confirm material specifications, product performance, compliance, sampling, production capabilities and delivery details before accepting orders.
- The enquiry form opens the visitor's email application; it is not a server-backed CRM or submission system.
