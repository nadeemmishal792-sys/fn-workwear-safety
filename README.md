# FN WORKWEAR & SAFETY

Premium editorial B2B website for FN Workwear & Safety, Sialkot, Pakistan.

## Website
- Responsive single-page website with desktop and mobile navigation.
- Product-family reference views for industrial workwear, high-visibility clothing, protective apparel and corporate uniforms.
- Product images are visual references; they are not proof that pictured items are FN-made products.
- SEO metadata, Open Graph identity, canonical URL, Organization structured data, favicon, robots.txt and sitemap.

## Enquiry form status
The current website form uses the visitor's email application (mailto:). It prepares an email addressed to fnworkwear@gmail.com; it does not send or store the enquiry automatically, and selected attachments must be added manually by the visitor.

A Google Apps Script receiver is included in google-apps-script/ as an optional server-backed route. It is NOT connected to the website yet. Follow google-apps-script/SETUP.md using the business Google account, deploy the script as a Web App, and configure its deployed /exec URL in the website integration before claiming that direct submissions or file uploads work. The backend currently documents a limit of 8 files and 8 MB combined; Google quotas apply.

## Publish and deploy
The .github/workflows/deploy.yml workflow builds the static site and deploys it to GitHub Pages on pushes to main and manual workflow dispatch. Check the latest GitHub Actions run and the public URL after every release; a successful build alone is not proof that the published site is reachable.

## Accuracy notes
- No certifications, audited facilities, compliance claims, manufacturing capacity, MOQ, lead times or export track record are asserted.
- Confirm material specifications, product performance, compliance, sampling, production capabilities and delivery details before accepting orders.
- Do not add customer reviews, client logos or business claims unless FN can substantiate them.
